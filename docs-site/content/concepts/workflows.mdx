# Workflows

A workflow is a Pydantic state class plus a graph. You build the graph with LangGraph's
`StateGraph`; AgentDeck compiles it, opens one sandbox workspace for the whole run, and
shares that workspace with every node — including any agent a node invokes.

```python
# .agentdeck/workflows/new_booking/workflow.py
from pydantic import BaseModel

from agentdeck.workflows import END, BaseWorkflow, StateGraph


class BookingState(BaseModel):
    request: str
    quote: str = ""


class NewBooking(BaseWorkflow):
    state = BookingState

    @classmethod
    def build_graph(cls) -> StateGraph:
        graph = StateGraph(cls.state)
        graph.add_node("quote", cls.quote)
        graph.set_entry_point("quote")
        graph.add_edge("quote", END)
        return graph

    @staticmethod
    def quote(state: BookingState) -> dict:
        return {"quote": f"€420 for {state.request}"}
```

Run it by name; the return value is the final state:

```python
import asyncio

from agentdeck import App


async def main() -> None:
    async with App.open() as app:
        state = await app.run_workflow("NewBooking", {"request": "Berlin -> Munich"})
        print(state["quote"])


asyncio.run(main())
```

## Nodes that do the interesting work

| Node | What it does |
|---|---|
| `AgentNode` | runs a `BaseAgent` subclass as a node; forwards its text deltas to the graph's custom stream |
| `SandboxAgentNode` | same, for a sandbox agent sharing the workflow's workspace |
| `SkillNode` | runs a [skill](/concepts/skills), optionally parsing stdout into a typed field |
| `LoadFileNode` | pulls a file out of the sandbox back into state |

`SkillNode(bundle, into="parsed")` stores the skill's typed output on that state field —
which requires the bundle to declare `metadata.output_schema` in `SKILL.md`, otherwise it
raises immediately rather than at runtime. `update=(state, result) -> dict` is the
schema-less escape hatch.

## Durability and human approval

Set `durable = True` and the graph compiles with a checkpointer (`AGENTDECK_CHECKPOINT_*`),
so a run is identified by `thread_id` and survives the process dying. Only then can a node
pause for a human:

```python
from agentdeck.workflows import BaseWorkflow, interrupt


class Approval(BaseWorkflow):
    durable = True

    @staticmethod
    def confirm(state) -> dict:
        decision = interrupt({"question": "Send this quote?"})
        return {"approved": decision == "yes"}
```

A paused run returns an `InterruptResult` — `{"type": "interrupt", "payload": …,
"thread_id": …}` — instead of a final state. Answer it with the thread id:

```python
import asyncio

from agentdeck import App


async def main() -> None:
    async with App.open() as app:
        paused = await app.run_workflow("Approval", {}, thread_id="quote-42")
        if paused["type"] == "interrupt":
            await app.resume_workflow("Approval", "quote-42", "yes")
        print(await app.pending_interrupts())  # the approval inbox


asyncio.run(main())
```

<Callout type="warning">
**An interrupt node re-runs from its start.** When the run resumes, everything in that node
before the `interrupt()` call executes a second time. Keep interrupt nodes pure — send the
email, charge the card, and write to your database in an *earlier* node, never in the one
that pauses.
</Callout>

## Timers

`sleep_until(when)` pauses a durable run until a timezone-aware moment, using the same
interrupt machinery with a `{"type": "timer", "wake_at": …}` payload — so a timer-paused
thread is distinguishable from a human-paused one in the inbox. Naive datetimes are
rejected.

AgentDeck runs no daemon: you own the cadence. `App.due_resumes()` lists timer threads whose
moment has passed, and `App.tick()` resumes every one of them.

## Streaming and composition

`App.run_workflow_stream()` yields a `node_update` per completed node, a `custom` event per
`get_stream_writer()` call, then one terminal `done` carrying the final state — and an
`interrupt` event in place of `done` when the run pauses.

`BaseWorkflow.as_tool()` turns the whole workflow into a tool an agent can call, which is
how a conversation reaches deterministic multi-step work.
