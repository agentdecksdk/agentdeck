# Capabilities

[Capabilities](/concepts/capabilities) covers the state of this feature: sandboxing is disabled
in the current `Agent`/`Deck` API, tracked separately for a future slice. There is no
`capabilities=` argument on `Agent` today, and no page here can make one exist.

The spec classes this page used to document field by field —
`CapabilitiesSpec`, `ShellSpec`, `FilesystemSpec`, `MemorySpec`, `CompactionSpec` — still live in
the codebase at `agentdeck.authoring.capabilities`, unchanged in shape, waiting for whatever
construction path sandboxing returns through. Read their docstrings directly if you need the
field-by-field detail before this page comes back.
