---
name: shift-notes
description: How to write a handover note when closing out a shift — use before filing one.
---

A handover note has three parts, in this order: what changed during the shift, what is still open,
and what the next shift should watch for.

Keep it to three sentences, one per part. If the user has not said what is still open, ask before
filing — a note that invents an open item is worse than no note.

File it against the date the shift ran, not the date it was written, if those differ.
